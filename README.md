# Adarsh Mohan — Portfolio

Personal site for backend and Generative AI work.

## Run locally

```bash
npm install --legacy-peer-deps
npm run dev
```

Open http://localhost:3000

## Host on Vercel

1. Upload this folder to GitHub (`https://github.com/saaxena`) or import it at [vercel.com/new](https://vercel.com/new).
2. Framework: **Next.js**
3. Install command: `npm install --legacy-peer-deps`
4. Optional env: `NEXT_PUBLIC_SITE_URL` = your live domain
